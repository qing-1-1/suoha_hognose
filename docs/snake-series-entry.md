# 多系列与个体录入

部署前先执行 `supabase/migrations/035_snake_multiple_series.sql`，再发布前端。此迁移依赖既有 028 及之前的迁移，保留旧系列名称并回填 `snakes.series_names`，新增受权限保护的系列字典和事务改名函数，同时更新公开档案筛选。

种群和自繁库的新增、编辑个体表单内可以勾选多个系列、新建系列或展开“编辑已有系列”修改名称。新建和改名立即保存；个体的系列归属随表单保存。取消个体表单不会撤销已经保存的系列名称变更。

系列改名同步更新所有关联个体；相同名称不会合并。旧版幼体登记或导入仍可写入单系列字段，由触发器转换为系列数组。旧 `series` 字段保留为展示文字，筛选、统计与配对关系使用数组成员关系。同一个体可能计入多个系列，因此系列计数之和可能大于个体总数。

日期支持原生日历、今天、清空及年月日分别选择。未确认的日期可留空，出生日期不得晚于今天，预计成熟日期不得早于出生日期。新增表单默认折叠补充资料和结构化基因；编辑时展开。

验证：`npm test`；`npx playwright test tests/browser/snake-entry.spec.js tests/browser/individual-photos.spec.js`；`npm run build`。

个体输入框内回车不会提交表单；Esc 与点击遮罩不会关闭编辑弹窗。有未保存改动时，点击取消或关闭按钮需要确认放弃，取消确认则继续保留表单。保存中禁用重复提交和关闭；只有保存成功才自动关闭。
